AtCoder Weekly Contest (AWC) の過去問から、条件に合わせてランダムに問題をピックアップするWebアプリケーション（単一HTMLファイル）です。

## 🌟 主な機能

- **問題の難易度指定**: A〜E問題から、対象としたい難易度を複数選択可能。
- **最新コンテストの自動計算**: AWCの開始日（2026年2月9日）から現在の日時を元に、最新のコンテスト（問題）番号を自動算出します。
- **複数問題のピックアップ**: 1回につき1〜5問まで指定して同時にルーレットを回せます。
- **除外設定（柔軟なブラックリスト）**: 既に解いた問題や、特定のコンテスト全体をルーレットの対象外に設定できます。
- **ワンクリックアクセス**: ルーレットの結果から、AtCoderの該当問題ページ（URL）へ直接ジャンプできます。
- **設定の保存機能**: 選択した難易度やピック数などの設定はブラウザ（ローカルストレージ）に自動保存され、次回アクセス時も復元されます。

## 🚀 使い方

1. `index.html` をGoogle ChromeやSafariなどのWebブラウザで開きます。
2. **ピックする問題**: 対象としたい難易度（A〜E）にチェックを入れます。
3. **最大のコンテスト番号**: ルーレットの対象上限となる番号を指定します（アクセス時に自動計算された値が入力されています）。
4. **ピックする問題数**: スライダーを動かして、1〜5問の間で設定します。
5. **除外設定**: （任意）対象外にしたい問題があれば、後述の「除外設定の書式」に従って入力します。
6. **「ルーレットを回す」ボタン**をクリックすると、アニメーションの後に結果が表示されます。
7. 結果のテキストをクリックすると、AtCoderの問題ページが別タブで開きます。

## ⚙️ 除外設定の書式

除外したいコンテスト番号と問題記号を **半角スペース** で区切って入力します。複数ある場合は改行してください。大文字・小文字は区別されません。

- `100 *` : コンテスト番号100の **すべての問題** を除外します。
- `108 d` : コンテスト番号108の **D問題のみ** を除外します。

**入力例:**
```text
100 *
108 d
108 E
120 *

```

## 💻 技術仕様

* **言語**: HTML5, CSS3, JavaScript (Vanilla / 外部ライブラリ非依存)
* **URL生成ルール**: `https://atcoder.jp/contests/awc{番号(4桁0埋め)}/tasks/awc{番号(4桁0埋め)}_{難易度(小文字)}`
* **自動計算ロジック**:
* 基準日: `2026-02-09 00:00:00`
* 現在の日時との差分（経過日数と週数）を計算し、1週間あたり5問ペースで進行する前提のロジックで現在の番号を算出しています。当日21時以降に新しいコンテストが解放される仕様を想定しています。
